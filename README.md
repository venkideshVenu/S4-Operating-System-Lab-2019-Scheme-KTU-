
# 🚀 S4 Operating System Lab – KTU (2019 Scheme)

 
> Practical Learning Repository for CS234 - Operating Systems Lab (2019 Scheme)  
> **Kerala Technological University (KTU)**

---

## 📌 About This Lab

This repository serves as a complete guide and practical notebook for the **S4 Operating System Lab** under the **2019 Scheme** of **KTU**. It is aimed at helping Computer Science students gain hands-on experience with fundamental OS concepts like:

- CPU Scheduling
- Memory Management
- Process Synchronization
- System Calls
- File & Disk Operations

## 🔬 Experiments Covered

Each experiment has its own folder with source code, problem statement, and simulation details.

| No. | Title                                | Description                                           | Code Link |
|-----|--------------------------------------|-------------------------------------------------------|-----------|
| 1   | Basic UNIX Commands                  | Introduction to common terminal commands              | [View](./UNIX%20Commands.pdf) |
| 2   | Shell Programming                    | Write shell scripts for basic automation              | [View](./Shell%20Programming) |
| 3   | System Calls                         | Understand file handling, fork, exec, etc. in C       | [View](./System%20Calls) |
| 4   | CPU Scheduling Algorithms            | FCFS, SJF, RR, Priority scheduling                    | [View](./CPU%20Scheduling) |
| 5   | Inter-Process Communication (IPC)    | Pipes, message queues, shared memory                  | [View](./Inter%20Process%20Communication) |
| 6   | Semaphore Implementation             | Producer-Consumer, Dining Philosophers problem        | [View](./Implement%20Semaphore) |
| 7   | Memory Allocation (Fixed Partition)  | First fit, best fit simulation                        | [View](./memoryAllocation.c) |
| 8   | Page Replacement Algorithms          | FIFO, LRU, Optimal algorithms                         | [View](./Page%20Replacement%20Algorithm) |
| 9   | Banker's Algorithm                   | Deadlock avoidance algorithm                          | [View](./bankersAlgorithm.c) |
| 10  | Deadlock Detection                   | System Resource Allocation Graph (RAG) simulation     | [View](./deadLockDetection.c) |
| 11  | File Allocation Strategies           | Contiguous, linked, indexed file allocation           | [View](./File%20Allocation) |
| 12  | Disk Scheduling                      | FCFS, SSTF, SCAN, LOOK                                | [View](./Disk%20Scheduling) |

## ⚙️ Installation & Setup

To get started locally:

```bash
# Clone the repository
git clone https://github.com/venkideshVenu/S4-Operating-System-Lab-2019-Scheme-KTU-.git

# Navigate to a specific experiment
cd S4-Operating-System-Lab-2019-Scheme-KTU-/CPU\ Scheduling
```

**Compiling C Programs:**

```bash
gcc filename.c -o output
./output
```

**Running Shell Scripts:**

```bash
bash scriptname.sh
```
